# Android screenshots

This folder is the current visual reference for the implemented Android app.

- One subfolder per page or major screen.
- Keep only the latest validated screenshot for each element/state.
- Use clear names based on the page and element shown.
- Store only real screenshots produced by the implemented app.
- Replace obsolete screenshots after validated UI changes.
- Use these images during implementation review to find and correct deviations from the requested result.

The permanent workflow rules are tracked in issue #27.
